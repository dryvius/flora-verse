## 1. 项目简介

FloraVerse
是一款以现实植物为入口的数字探索与收藏产品。用户通过手机摄像头拍摄现实植物，系统借助植物识别服务识别物种，用户确认结果后，将本次发现记录为一株独立的数字植物，并收入个人植物谱。

**V1.0 的核心体验：发现一株真实植物，将它变成自己收藏的一株数字植物。**

## 2. V1.0 产品范围

### 本期建设

-   用户基础身份与个人收藏空间
-   摄像头拍摄、相册选图
-   图片上传与 AI 植物识别
-   识别候选展示、人工确认与纠错
-   植物物种档案
-   植物个体收藏
-   收录历史记录
-   植物谱浏览、搜索、筛选和统计
-   基础探索成就

### 本期明确不做

-   植物等级、经验、属性成长
-   植物战斗、排位和匹配
-   实时联机、好友、公会
-   植物交易
-   复杂 AR 场景
-   基于地理位置的稀有植物刷新机制

## 3. 核心概念

  --------------------------------------------------------------------------------------
  概念                                说明
  ----------------------------------- --------------------------------------------------
  PlantSpecies / 植物物种             植物学意义上的标准物种记录，同一物种可被多次发现

  PlantInstance / 植物个体            用户每次成功收录后生成的独立收藏对象

  PlantCapture / 收录记录             一次拍摄、识别、确认和收录过程的记录

  UserCollection / 用户图鉴           用户已发现的物种集合及收藏统计

  RecognitionTask / 识别任务          图片识别过程及其状态、候选结果
  --------------------------------------------------------------------------------------

## 5. 当前关键产品原则

1.  **物种与个体分离**：物种是公共标准数据，个体是用户的私人收藏。
2.  **识别与收录分离**：AI 识别只是建议，用户确认后才创建收藏。
3.  **重复收录允许存在**：重复收录可以形成不同个体，但不会增加已发现物种数。
4.  **真实照片是收藏的重要组成**：每株个体尽量保留对应的发现照片。
5.  **不鼓励采摘**：拍照记录即可，不要求用户获取或破坏真实植物。
6.  **隐私优先**：地理位置默认不公开，精确位置不是收录的必要条件。
7.  **服务端可信**：物种归一化、收藏创建、统计和权限校验由服务端负责。

## 6. 待决策事项

本项目仍处于产品定义阶段，以下内容在验证前不视为最终承诺：

-   首批植物物种库的规模和数据来源
-   植物识别服务供应商及成本
-   是否保留原始照片、保存期限与用户删除策略
-   是否采集位置，以及位置精度和默认策略
-   植物稀有程度的评价口径
-   首发用户体系：微信授权登录还是手机号等补充方式
-   图鉴完成度的统计分母
-   是否允许用户为植物个体设置昵称
