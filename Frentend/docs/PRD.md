# FloraVerse V1.0 产品需求文档（PRD）

-   文档状态：初稿，待产品决策确认
-   产品阶段：MVP
-   目标平台：微信小程序优先；架构考虑 H5、iOS、Android
-   当前范围：植物拍摄、识别、收录、收藏与植物谱

## 1. 产品概述

### 1.1 产品定位

FloraVerse 是一款基于现实植物拍摄和 AI
识别的数字植物探索与收藏产品。用户通过手机发现现实植物，拍摄照片并识别物种，经用户确认后生成独立的数字植物个体，纳入个人植物谱。

### 1.2 产品愿景

让用户通过手机镜头发现自然，通过数字图鉴记录每一次植物发现，逐步建立个人化、可持续扩展的植物收藏档案。

### 1.3 核心价值

-   **发现价值**：帮助用户认识身边的植物。
-   **收藏价值**：每次成功收录都留下独立收藏记录。
-   **知识价值**：通过物种档案了解植物名称、分类和特征。
-   **记录价值**：回顾自己在不同时间发现过哪些植物。

### 1.4 核心循环

发现植物 → 拍摄/选图 → AI 识别 → 用户确认 → 创建植物个体 → 收入植物谱 →
浏览档案与探索统计 → 继续发现。

## 2. 目标用户与使用场景

### 2.1 目标用户

-   对植物、自然、园艺感兴趣的普通用户
-   喜欢图鉴收集、打卡和成就的用户
-   希望通过轻量方式学习植物知识的用户
-   喜欢记录生活与探索经历的用户

### 2.2 典型场景

1.  用户在公园看到一株不认识的植物，打开相机拍摄并识别。
2.  用户在家中拍摄盆栽，将其加入植物谱。
3.  用户从相册选择过去拍摄的植物照片进行识别。
4.  用户发现识别结果不准确，选择候选物种或手动搜索。
5.  用户打开植物谱，查看已发现物种、重复收藏个体和发现时间。

## 3. 产品目标与非目标

### 3.1 V1.0 目标

-   打通拍摄到收藏的完整闭环。
-   识别结果可解释、可确认、可纠错。
-   物种、个体、收录记录的数据关系清晰。
-   用户可以方便地查看、搜索和管理收藏。
-   具备基础的失败恢复和隐私控制能力。

### 3.2 非目标

本期不实现：

-   植物养成、等级、经验、属性和技能
-   PvP/PvE 战斗、匹配、排行榜
-   好友、公会、交易和社交动态
-   复杂 AR、实时地图和地理围栏
-   付费抽取或以付费决定植物稀有度

## 6. 核心业务规则

### 6.1 物种与个体

-   一个标准物种可以关联多个植物个体。
-   一个植物个体只关联一个最终确认的标准物种。
-   一个收录记录对应一次用户发起的收录流程。
-   一次收录成功最多创建一个植物个体。
-   同一物种重复收录会增加个体数量，不增加已发现物种数量。

### 6.2 首次发现

首次发现定义为：用户第一次成功创建某一标准物种的植物个体。

首次发现由服务端事务判断，不能依赖客户端本地缓存。

### 6.3 识别与确认

-   AI 结果不是最终物种身份。
-   用户确认或手动选择后，才创建收录。
-   用户可以在创建前取消。
-   识别失败不产生植物个体。
-   识别纠错应记录原始识别结果和用户最终选择，便于后续质量分析。

### 6.4 图片与位置

-   植物收录不要求用户采摘植物。
-   精确地理位置不是核心流程的必要条件。
-   位置采集必须明确告知用途并取得适当授权。
-   默认不向其他用户公开精确位置。
-   用户应能查看并管理自己上传的照片；删除策略需在上线前确认。

## 7. 非功能需求

### 7.1 性能

-   页面首屏应保持轻量，图片采用缩略图和懒加载。
-   上传和识别过程必须提供明确状态。
-   识别耗时受第三方服务影响，应记录 P50/P95 指标。
-   列表使用分页或游标加载，避免一次性加载全部收藏。

### 7.2 稳定性

-   上传失败可重试。
-   识别任务有超时和失败状态。
-   收录创建接口支持幂等。
-   弱网和重复点击不应产生重复收藏。

### 7.3 安全与隐私

-   图片上传使用受控接口或短时有效上传凭证。
-   用户只能访问自己的私有收藏记录。
-   不在客户端保存服务端密钥。
-   日志避免记录不必要的个人信息和图片公开地址。
-   提供隐私政策、用户协议及必要的授权说明。

### 7.4 可扩展性

-   物种数据与用户收藏数据分离。
-   识别供应商通过适配层接入。
-   客户端不直接承担物种归一化和收藏统计的权威逻辑。
-   为未来养成、对战预留扩展空间，但不在 V1.0 实现相关规则。

## 8. 数据指标

建议采集以下产品指标：

-   拍摄入口点击率
-   拍摄成功率
-   图片上传成功率
-   识别成功率
-   用户确认率
-   用户纠错率
-   识别到收录的转化率
-   人均已发现物种数
-   人均收藏个体数
-   7 日内再次收录用户比例
-   收藏列表访问率

指标应以匿名化或最小必要方式采集，并符合适用隐私要求。

## 9. MVP 验收标准

一个新用户能够完成以下完整路径：

1.  进入小程序并建立个人空间。
2.  授权摄像头或选择相册图片。
3.  上传一张可识别的植物照片。
4.  获得识别结果及候选信息。
5.  确认一个物种。
6.  成功创建一株植物个体。
7.  在植物谱中看到该物种和个体。
8.  再次收录同一物种，物种数不变、个体数增加。
9.  在详情页查看每次收录的照片和时间。
10. 在识别失败、上传失败或权限拒绝时获得可理解的处理方式。
