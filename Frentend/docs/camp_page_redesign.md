# 《FloraVerse》营地首页（Camp Page）重构与改造指南

- 文档状态：已落地（个人温室布局）
- 对应页面：`src/pages/home/index.vue`
- 关联文档：`floraverse_ui.md`、`floraverse_ui_v2.md`、`GAME_DESIGN.md`

---

## 1. 产品定位与核心目标

### 1.1 功能边界

| 页面 | 定位 |
|------|------|
| **营地** | 个人博物工作室 / 温室大棚：环境气象、明星植物实时状态、近期收获 |
| **图鉴** | 完整标本合集与大列表 |
| **收录** | 野外探索主入口（底部中央） |
| **我的** | 资料、战力总览、设置 |

营地首页**不再**铺满多列大卡片网格；完整合集沉淀在图鉴。

### 1.2 玩法锚点

凸显**环境因子对植物属性的影响**：季节 / 天气 / 温度使基础战力产生动态波动，为对战系统铺垫。

## 2. 黄金四段式布局

```
+--------------------------------------------------+
| 1. 顶部极简状态栏 (Player Header)                  |
|    头像 / 昵称 / 标本总数 (已发现/图鉴总量)         |
+--------------------------------------------------+
| 2. 环境与物候气象站 (Weather & Field Note)         |
|    仲秋 · 晴 · 22℃ + 环境加成说明                  |
+--------------------------------------------------+
| 3. 温室主视觉舱 (Centerpiece)                      |
|    单株明星植物 + 战力 / 天气加成 / 位置 / 状态     |
+--------------------------------------------------+
| 4. 近期收获横向流 (Recent Acquisitions)            |
|    横向滑动 1~3 个新标本 → 入口跳转图鉴            |
+--------------------------------------------------+
| [底部导航] 营地 | 图鉴 | [+] 探索 | 排行 | 我的     |
+--------------------------------------------------+
```

## 3. UI 视觉规范

- **背景**：`#0D1C14` + 低透明度颗粒噪点 / 暗金径向氛围。
- **边框**：黄铜鎏金双层细线（外粗内细），维多利亚角花可用 L 型刻度代替。
- **天气彩蛋**：晴天斜射暖光；雨天水汽条纹；薄雾柔光罩。
- **字体**：物种名、核心战力、区块标题使用宋体 / Georgia 衬线族。
- **清爽原则**：首屏以主视觉舱为绝对中心，避免统计卡墙与多模块并列。

---

## 4. 数据契约（`HomeOverview`）

```ts
interface HomeOverview {
  userDisplayName: string
  discoveredSpeciesCount: number
  instanceCount: number
  catalogSpeciesTotal: number
  weatherStation: CampWeatherStation
  featuredPlant: CampFeaturedPlant | null
  recentInstances: InstanceCard[] // 最多 3，排除明星株
}
```

- 气象：`constants/camp-climate.ts` 按月份映射天气、温度、加成百分比与文案。
- 明星株：当前收藏中 `baseCombatPower` 最高的个体；战力 = 基础 × (1 + 环境加成)。
- 近期收获：按收录时间倒序，物种去重，排除明星株，上限 `CAMP_RECENT_RAIL_LIMIT`。

## 6. 验收标准

1. 首页无 2×N 大卡片网格。
2. 首屏可同时读出：身份、气象、明星植物战力与加成、近期收获入口。
3. 点击抬头 → 我的；主舱 / 收获条 → 个体详情；「图鉴 ›」→ 图鉴 Tab。
4. 空收藏时展示空温室 CTA，引导探索。
5. 视觉为暗绿鎏金 + 衬线标题，无荧光 / 无运营贴片墙。
