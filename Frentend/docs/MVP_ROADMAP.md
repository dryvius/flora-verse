# FloraVerse V1.0 MVP 开发路线与验收计划

## 1. 目标

以微信小程序为首发载体，完成现实植物拍摄、AI
识别、用户确认、植物收录和个人植物谱收藏闭环。

## 2. 开发原则

-   先验证植物识别服务，再大规模开发界面。
-   先完成端到端闭环，再扩展边缘功能。
-   采用模块化单体后端，避免 MVP 过早微服务化。
-   领域模型独立于 UI 框架。
-   服务端负责权威识别任务状态、收藏创建和统计。
-   每个里程碑都有可演示、可验收的交付物。

## 3. 里程碑

### M0：产品与技术验证

任务： - 明确首批目标植物类别。 - 收集代表性测试照片。 - 对比 2-3
个植物识别服务。 - 验证中文名、学名、候选列表和识别失败处理。 -
验证微信小程序摄像头、相册、上传能力。 - 明确图片存储和隐私策略。

交付： - 识别服务评估记录 - 技术验证 Demo - 已确认的 MVP 决策清单

验收： - 真实样本测试集覆盖常见、相似、模糊和多主体场景。 -
能明确识别服务的能力边界、费用和调用限制。

### M1：项目基础设施

任务： - 初始化代码仓库与工程规范。 - 建立小程序基础页面和导航。 -
建立后端项目和环境配置。 - 建立用户身份与权限基础。 -
建立数据库迁移机制。 - 建立统一 API 错误结构和日志规范。

交付： - 可运行的小程序 - 可运行的后端服务 - 数据库基础表 - 开发环境说明

验收： - 用户可进入个人空间。 - 用户数据隔离测试通过。

### M2：植物物种数据基础

任务： - 确定物种数据来源与授权。 - 建立 PlantSpecies 和 Alias
数据结构。 - 建立物种搜索接口。 - 建立物种导入、去重和审核流程。 -
准备首批种子数据。

交付： - 物种基础库 - 物种搜索 API - 数据导入脚本

验收： - 中文名、学名和别名可以检索到同一标准物种。 -
不会因同物异名产生明显重复记录。

### M3：拍摄与识别

任务： - 摄像头拍摄。 - 相册选图。 - 图片预览和校验。 - 图片上传。 -
识别任务创建、查询和状态展示。 - 识别供应商适配层。 -
候选结果和失败重试。

交付： - 完整的图片识别流程

验收： - 权限拒绝、上传失败、识别失败均有可恢复处理。 -
识别结果能映射到标准物种库或进入未收录流程。

### M4：收录与收藏

任务： - 用户确认物种。 - 收录接口。 - 幂等控制。 -
首次/重复发现判断。 - PlantInstance 和 PlantCapture 创建。 -
收录成功页面。

交付： - 从识别结果到收藏成功的完整闭环

验收： - 同一请求重试不会生成重复个体。 -
同一物种重复收录会创建新个体。 - 首次发现状态正确。

### M5：植物谱与个人中心

任务： - 物种图鉴列表。 - 个体收藏列表。 - 物种详情。 - 个体详情。 -
搜索、筛选和排序。 - 首页统计。 - 基础成就（如资源允许）。

交付： - 可持续使用的个人植物谱

验收： - 物种数、个体数、收录记录数统计口径一致。 -
用户只能查看和管理自己的收藏。

### M6：测试、体验优化与发布准备

任务： - 功能回归测试。 - 弱网与异常测试。 - 图片性能优化。 -
隐私政策和用户协议。 - 小程序平台审核准备。 - 监控和错误上报。 -
小范围内测。

交付： - MVP 候选发布版本 - 测试报告 - 发布检查清单

验收： - 核心闭环稳定完成。 - 无阻断级问题。 -
隐私、权限和数据删除流程明确。

## 4. 建议开发顺序

不要严格按"先前端全部完成、再后端全部完成"的方式开发。推荐纵向切片：

1.  建立最小用户和物种接口。
2.  做通一次图片上传和识别。
3.  做通一次确认和收录创建。
4.  做通植物谱读取。
5.  再完善筛选、统计、成就和体验。

这样每个阶段都能看到真实业务结果。

## 5. 测试重点

### 识别测试集

至少覆盖： - 清晰单株植物 - 叶片特写 - 花朵特写 - 多株植物同框 -
相似物种 - 背景复杂 - 光线不足 - 植物主体不明显 - 非植物图片

### 业务测试

-   首次收录
-   同物种重复收录
-   不同用户收录同一物种
-   用户纠正识别结果
-   收录请求重复提交
-   上传成功但识别失败
-   识别成功但收录创建失败
-   用户删除个体后的统计变化

### 隐私与权限测试

-   未登录访问私有收藏
-   用户 A 访问用户 B 的个体
-   图片资源 URL 是否可被非授权访问
-   拒绝摄像头/相册权限
-   用户删除数据后的资源处理

## 6. MVP 发布门槛

-   核心收录闭环通过验收。
-   物种与个体统计准确。
-   重复请求不会产生重复收藏。
-   关键异常有明确恢复方式。
-   隐私政策、图片处理和位置策略明确。
-   已完成目标设备上的相机、相册和上传测试。

## 7. 后续版本候选（不属于 V1.0）

-   植物园与展示空间
-   现实探索地图
-   季节与天气主题活动
-   植物个体外观变异
-   AR 展示
-   养成系统
-   植物对战
-   好友与联机
